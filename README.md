# Perfil NFC — Nancy Ceballos Medrano

Página de presentación profesional para Vextrum Geomatics. Proyecto estático, sin dependencias ni servicios externos.

## Publicar en GitHub Pages

1. En la cuenta `Nancystrategyvextrum-prog`, crear un repositorio público llamado `perfil-nfc-nancy`.
2. Subir **el contenido de esta carpeta** a la raíz del repositorio (`index.html`, `styles.css`, `.vcf` y carpeta `assets`). No subir la carpeta contenedora como subcarpeta.
3. Ir a **Settings → Pages**. En **Build and deployment**, seleccionar **Deploy from a branch**, rama **main**, carpeta **/(root)**, y guardar.
4. Esperar la publicación y abrir `https://nancystrategyvextrum-prog.github.io/perfil-nfc-nancy/`.
5. Probar WhatsApp, correo, LinkedIn y **Guardar contacto** en el teléfono antes de grabar la URL en NFC Tools.

## Privacidad

Esta página es pública. La etiqueta `noindex,nofollow` solicita a buscadores no indexarla, pero **no** impide que otras personas con la dirección la vean. El repositorio público también deja visibles sus archivos.

## Cambios

- Reemplazar `assets/foto-nancy.png` y `assets/logo-vextrum.png` solo si se desea actualizar los originales.
- Editar `index.html` para actualizar textos y enlaces.
- Editar `nancy-ceballos-medrano.vcf` para actualizar la ficha descargable.

## Correo universal (v3)

El botón «Enviar correo» utiliza mailto: y abre la aplicación de correo predeterminada del visitante. Si no tiene una configurada, puede utilizar «Copiar correo» y pegar la dirección en Gmail, Outlook u otro servicio. El botón de copiar incluye una alternativa para probar desde archivos locales.
